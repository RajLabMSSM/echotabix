# Filter VCF query samples

Only include certain samples in a VCF query. If at least one sample is
supplied, returns a
[ScanVcfParam](https://rdrr.io/pkg/VariantAnnotation/man/ScanVcfParam-class.html).
Otherwise, returns the original
[GRanges](https://rdrr.io/pkg/GenomicRanges/man/GRanges-class.html)
object (`gr`).

## Usage

``` r
filter_vcf_query_samples(gr, samples = character(), verbose = TRUE)
```

## Arguments

- gr:

  A [GRanges](https://rdrr.io/pkg/GenomicRanges/man/GRanges-class.html)
  object generated by
  [construct_query](https://rajlabmssm.github.io/echotabix/reference/construct_query.md).

- samples:

  \[Optional\] Sample names to subset the VCF by. If this option is
  used, the
  [GRanges](https://rdrr.io/pkg/GenomicRanges/man/GRanges-class.html)
  object will be converted to a
  [ScanVcfParam](https://rdrr.io/pkg/VariantAnnotation/man/ScanVcfParam-class.html)
  for usage by
  [readVcf](https://rdrr.io/pkg/VariantAnnotation/man/readVcf-methods.html).

- verbose:

  Print messages.

## Value

[GRanges](https://rdrr.io/pkg/GenomicRanges/man/GRanges-class.html) or
[ScanVcfParam](https://rdrr.io/pkg/VariantAnnotation/man/ScanVcfParam-class.html)
object.
