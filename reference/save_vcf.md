# Save VCF

Save a VCF file to disk.

## Usage

``` r
save_vcf(vcf, query_save, save_path, verbose = TRUE)
```

## Arguments

- query_save:

  Whether to save the results of the query on disk. *Note*: Writing to
  disk can take some time.

- save_path:

  File path to save query subset to (as VCF).

- verbose:

  Print messages.

## Value

save_path
